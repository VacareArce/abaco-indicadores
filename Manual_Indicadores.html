Guía de Integración:
Nuevos Indicadores

Este documento establece el procedimiento estándar para agregar nuevos indicadores al Dashboard de ABACO. Todo el proceso requiere la edición de dos archivos locales y conocer previamente los accesos de Looker Studio.

Fase 0: Recolección de Datos

Asegúrese de recopilar la siguiente configuración exacta antes de iniciar la programación:

  • ID del Sistema: Una palabra clave sin espacios (ej. pesoIdeal).
  • ID de Looker Studio: El identificador único del tablero, localizado numéricamente en su URL después del segmento /page/ (ej. p_jlgbdeha4c).
  • Ficha Técnica: El enlace público de Google Drive con el archivo en formato PDF.
  • Nivel Geográfico: El entendimiento absoluto de si los datos en BigQuery están detallados por Municipio o consolidados por Departamento.
  • ID Sequencial de Datos: El identificador de fuente de datos asignado internamente por Looker Studio (ej. ds025).

Paso 1: Configurar el Diccionario (JS)

El archivo js/menu_lista_tableros.js es el responsable de mapear las conexiones visuales.

  1. Abra el archivo js/menu_lista_tableros.js.
  2. Encuentre el bloque maestro de la variable var tableros = {.
  3. Inyecte al final del bloque su nuevo indicador con el siguiente formato estricto:
"TU_ID_DEL_SISTEMA": { 
    "tablero": "EL_ID_DE_LOOKER_STUDIO", 
    "ficha": "EL_ENLACE_DE_GOOGLE_DRIVE"
}
⚠ Regla de Comas en JavaScript
Debe separar cada bloque de configuración con una coma (,). Si inserta su indicador al final de la lista, garantice que el penúltimo contenga una coma y que el suyo de cierre se omita. El inclumplimiento de esto "romperá" la interfaz entera.

Paso 2: Alinear el Motor de Filtrado (Granularidad)

El sistema usa inyección directa a las fuentes del dashboard en `actualizarTablero()`. Sin este paso, el filtro geográfico fallará cediendo paso a resultados incorrectos.

  1. Abra el archivo central index.html.
  2. Localice en el código fuente la función llamada actualizarTablero(codeMunicipio).
  3. Identifique la cadena gigantesca de texto (url2) donde residen los parámetros ds001 al actual.
  4. Anexe su nueva fuente guiándose por estas reglas matemáticas:

► Para bases detalladas por Municipio:
Use estrictamente el parámetro municipal.

+'"ds025.pcodigom":"'+codeMunicipio+'"'+','

► Para bases consolidadas (Departamentales):
Omitir reglas municipales y forzar el cruce general.

+'"ds025.pcodigom":"'+codeDep+'"'+','

Paso 3: Ensamblar la Interfaz Principal (HTML)

El componente final es generar el ancla interactiva para el menú superior horizontal.

  1. Sin cerrar index.html, desplácese hacia arriba buscando el contenedor <div id="horizontal-menu">.
  2. Despliegue las listas (dropdown-content) hasta hallar el sitio perfecto para la nueva herramienta.
  3. Cree la etiqueta HTML, vinculándola a su recién creado ID del sistema:
<li><a class="submenu-item" onclick="cambiarMapa('TU_ID_DEL_SISTEMA')">Ver Indicador</a></li>

Protocolo de Errores y Diagnóstico

Guarde con Ctrl+S todos los archivos y refresque su navegador presionando F5.

  • Fallo Masivo (Pantalla totalmente blanca o no se dibuja el menú): Refleja una violación en el uso de las comas o sintáxis de llaves en el Paso 1.
  • Inactividad al pulsar el botón: Causa directa de un nombre disparejo o desfasado entre el `onclick` de su Paso 3 y el diccionario de su Paso 1. El lenguaje diferencia entre mayúsculas y minúsculas de forma estricta.
  • Dato incongruente (Filtro geográfico roto): Falla humana en la discriminación del Paso 2, uso erróneo de codeDep en lugar de codeMunicipio, u olvido total de integrar la lógica en la función central.
